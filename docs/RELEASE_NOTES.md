Global Protector WiFi v0.2.0 公开预览版。

- 重做主界面，仅显示连接状态和“启动 / 停止”操作。
- 主界面移除 IP、DNS、日志表单、口号及说明段落。

下载 `GlobalProtectorWiFi.exe` 或完整解压便携包。先停止旧版本，再运行新版；不要同时运行旧脚本和助手。
