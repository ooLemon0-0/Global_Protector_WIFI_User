Global Protector WiFi v0.3.1 公开预览版。

- 点击启动时，缺少 VPN 门户、账号或密码会自动弹出登录窗口，填完整后才能继续。
- 启动时自动打开 GlobalProtect 并辅助连接固定启用，删除自动连接及自动打开客户端的开关。
- 取消填写保持未启动状态，不触发管理员提权或网络修改；停止和恢复操作不受登录必填限制。
- 兼容已有加密登录信息，旧版关闭自动连接的选项不再生效。记住登录信息仍可自由选择，使用当前 Windows 用户加密保存。
- 保留原有临时分流、网络恢复、被动重连和登录窗口身份核验。

本地与 CI 测试覆盖必填启动门槛、弹窗按钮状态、旧配置迁移和加密保存。真实账号自动登录尚未实测；网页、验证码和证书确认仍需手动处理。请先停止并退出旧版，再运行新版。
