轻量 Windows 桌面助手的首个公开预览版。

- 单个原生 EXE，无需安装，无额外包下载。
- 中文界面、系统托盘、打开 GlobalProtect；不代替用户打开远程桌面。
- VPN 断开后恢复网络并继续待命，重连后自动重新应用；支持已验证物理网关的快速重连。
- 多个 IPv4 目标、自动检测物理网关、自动探测 VPN DNS。
- 临时主机路由与默认路由分流、快照恢复、异常恢复入口、本机诊断日志。
- 不包含个人 IP、VPN 网关、账号或历史日志。

下载 `GlobalProtectorWiFi.exe`，或完整解压 portable ZIP。首次点击开启会请求管理员权限。先开启助手，再连接 GlobalProtect。

助手不保存或填写账号密码。快速登录由官方 GlobalProtect 的 Save User Credentials / SSO 及公司认证策略控制。

公开版已进行离线行为测试、Windows 构建和本机只读启动/界面检查；源逻辑曾在一套 GlobalProtect 网络中成功实测，自动 DNS、多目标及其他 VPN 环境仍需要反馈验证。公司强制 DNS 或路由策略可能不兼容，IPv6 默认隧道暂不支持。程序尚未进行商业代码签名。

出现异常时先断开 VPN，再点击“停止并恢复”。反馈日志前请脱敏 IP 和本机路径。
