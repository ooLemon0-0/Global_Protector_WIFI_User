Global Protector WiFi v0.3.2 公开预览版。

- 修复 GlobalProtect 5.2 原生登录窗口被误判为“需手动登录”：兼容仅通过辅助描述提供标签的输入框，并识别经核验的原生控件编号。
- 在本机实际验证自动点击连接、填写已保存的账号密码及提交登录，用户确认自动操作生效。
- 登录失败显示具体结果，并增加不含凭据值的本机阶段诊断日志。
- 修复连接切换期间 VPN 路由暂时消失时的 CIM 查询错误；等待路由连续稳定后再修改网络，可随时停止等待。
- 保留必填登录、固定启用自动连接、当前用户加密保存，以及原有网络恢复机制。

测试覆盖本机原生登录控件适配、必填门槛、旧配置迁移、加密保存、路由暂失后的稳定等待与取消。网页、验证码和证书确认仍需用户处理。当前会话可继续使用；下次启动前停止并退出旧版，再运行新版。
