Global Protector WiFi v0.3.0 公开预览版。

- 主界面增加用途说明：连接 GlobalProtect 时保留普通网络访问。
- 登录设置中可预输入 VPN 门户、账号、密码，选择辅助连接及本机加密记忆。
- 对核验过的官方原生窗口尝试一次连接、填写和提交；不同门户、不同用户、非官方程序及不明确的窗口不接收凭据。
- 网页登录、验证码和证书确认仍需用户处理；不反复提交错误密码。
- 密码不进入命令行、设置文本、日志或仓库。可选记忆使用 Windows DPAPI 当前用户加密；UAC 通过一次性加密文件交接。
- 保留默认分流目标、网络恢复和被动重连处理。

辅助登录属于客户端 UI 兼容功能：存储、门户绑定、保护条件和模拟逻辑测试通过，且本机客户端签名核验通过；没有使用真实账号密码进行自动登录实测。遇到不兼容窗口会提示手动登录。请先停止旧版，再运行新版。
